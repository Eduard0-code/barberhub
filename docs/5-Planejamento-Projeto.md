# 5. Planejamento do Projeto

Este capítulo consolida a organização das atividades do time durante o desenvolvimento do BarberHub.

## 5.1. Divisão de Papéis

### Equipe
- Álan Christian de Araújo Lima

### Papéis por frente de trabalho
- Gestão e acompanhamento: organização de entregas, reuniões e revisão de marcos.
- Front-end: construção das telas de agendamento, avaliação, estoque, financeiro e indicadores.
- Back-end: implementação das APIs, regras de negócio e integração com banco de dados.
- Banco de dados: modelagem, scripts SQL, carga inicial e ajustes de esquema.
- Documentação: atualização contínua dos artefatos, BPMN, requisitos e interface.
