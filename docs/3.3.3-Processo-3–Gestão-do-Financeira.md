### 3.3.3 Processo 3 – (Gestão Financeira)
O processo de gestão financeira tem como objetivo registrar e controlar os valores recebidos pelos serviços realizados na barbearia.No cenário atual (AS IS), o controle financeiro é feito manualmente, geralmente por anotações, o que pode gerar erros e falta de organização. 

No cenário proposto (TO BE),após o barbeiro concluir o serviço no sistema,ele registra automaticamente os serviços realizados com seus valores, permitindo que o Barbeiro tenha uma visão clara do faturamento diário.Esse processo contribui para melhor controle financeiro, redução de erros e maior organização do negócio.

O fluxo é iniciado na raia do Barbeiro com o acesso a aba financeiro para conferência dos indicadores de desempenho do dashboard.Caso o usuário identifique que os dados estão atualizados, o processo é finalizado apenas com a consulta.

No entanto, havendo necessidade de processar novos registros, o usuário aciona o comando "Atualizar".Nesse momento, o fluxo passa para a raia do Sistema, que de forma automática e simultânea, realiza três ações críticas:
Recalcula as métricas financeiras dos cards superiores;
Atualiza os status dos registros na tabela de atendimentos;
Plota os novos dados no gráfico de evolução semanal.

O sistema consolida essas informações e apresenta o dashboard atualizado ao usuário, encerrando o ciclo com a garantia de que os dados financeiros refletem o estado atual do negócio.

##### 3.3.3.2  Detalhamento das atividades do usuário (user tasks)

Os tipos de dados utilizados no processo são:

* Área de texto: campo de texto de múltiplas linhas
* Caixa de texto: campo de texto de uma linha
* Lista: campo de lista suspensa
* Número: campo numérico
* Data: campo do tipo data (dd-mm-aaaa)
* Hora: campo do tipo hora (hh:mm:ss)
* Data e Hora: campo do tipo data e hora (dd-mm-aaaa, hh:mm:ss)
* Seleção única: campo com opções mutuamente exclusivas
* Seleção múltipla: campo com múltiplas opções selecionáveis
