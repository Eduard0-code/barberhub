### 3.3.3 Processo 3 – (Gestão do Financeira)
O processo de gestão financeira tem como objetivo registrar e controlar os valores recebidos pelos serviços realizados na barbearia.No cenário atual (AS IS), o controle financeiro é feito manualmente, geralmente por anotações, o que pode gerar erros e falta de organização. 

No cenário proposto (TO BE),após o barbeiro concluir o serviço no sistema,ele registra automaticamente os serviços realizados com seus valores, permitindo que o Barbeiro tenha uma visão clara do faturamento diário.Esse processo contribui para melhor controle financeiro, redução de erros e maior organização do negócio.

O fluxo é iniciado na raia do Cliente pelo evento "Atendimento finalizado", que leva à tarefa manual de "Realizar pagamento". Simultaneamente, na raia do Barbeiro, o profissional executa a tarefa de "Informar serviço realizado". Ambas as ações convergem para a raia do Sistema, onde a tarefa automática de "Registrar pagamento" é disparada. Após o registro, o sistema executa a atualização dos valores na tarefa "Atualizar caixa". O processo se encerra na própria raia do Sistema com o evento final "Pagamento registrado", indicando que a transação financeira foi concluída com sucesso.

##### 3.3.3.2  Detalhamento das atividades do usuário (user tasks)

Os tipos de dados utilizados no processo são:

* Área de texto: campo de texto de múltiplas linhas
* Caixa de texto: campo de texto de uma linha
* Lista: campo de lista suspensa
* Número: campo numérico
* Data: campo do tipo data (dd-mm-aaaa)
* Hora: campo do tipo hora (hh:mm:ss)
* Data e Hora: campo do tipo data e hora (dd-mm-aaaa, hh:mm:ss)
* Seleção única: campo com opções mutuamente exclusivas
* Seleção múltipla: campo com múltiplas opções selecionáveis

**1 Informar serviço realizado**
| **Campo** | **Tipo**       | **Restrições** | **Valor default** |
| --------- | -------------- | -------------- | ----------------- |
| serviço realizado   | lista          | obrigatório    | -                 |
| valor  | Número         | obrigatório    | -                 |
| forma de pagamento   | Seleção única          | obrigatório    | -                 |
| cliente   | Caixa de texto         | obrigatório    | -                 |

| **Comandos**              | **Destino**     | **Tipo** |
| ------------              | --------------- | -------- |
| confirmar pagamento       | Registrar pagamento | automático  |


**2 Registrar pagamento**
| **Campo** | **Tipo** | **Restrições**                  | **Valor default** |
| --------- | -------- | ------------------------------- | ----------------- |
| validação | Sistema  | campos obrigatórios preenchidos | automático        |

| **Comandos** | **Destino**     | **Tipo** |
| ------------ | --------------- | -------- |
| atualizar       | Atualizar caixa | automático  |


**3 Atualizar caixa**
| **Campo**      | **Tipo** | **Restrições** | **Valor default** |
| ------------   | -------- | -------------- | ----------------- |
| total recebido | Número   | automático     | atualizado        |

| **Comandos** | **Destino**     | **Tipo** |
| ------------ | --------------- | -------- |
| finalizar    | Fim do processo | default  |
