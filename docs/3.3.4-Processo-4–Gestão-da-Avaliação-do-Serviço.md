### 3.3.4 Processo 4 – (Gestão da Avaliação do Serviço)

O processo de avaliação do serviço tem como objetivo coletar a opinião dos clientes sobre o atendimento realizado, permitindo melhorar a qualidade dos serviços prestados.No cenário atual (AS IS), as avaliações são informais ou inexistentes, ocorrendo apenas verbalmente ou por redes sociais. 

No cenário proposto (TO BE), o sistema permite que o cliente (Lucas) avalie o serviço diretamente na plataforma, registrando nota e comentário.Isso permite que Roberto acompanhe a satisfação dos clientes e identifique oportunidades de melhoria.

O fluxo tem início na raia do Cliente com o evento "Atendimento finalizado", que dispara uma sequência de tarefas manuais: o cliente acessa a área de avaliação, informa a nota do serviço, escreve um comentário e, por fim, envia a avaliação, com a possibilidade de editar ou excluir mais tarde. Ao enviar, o fluxo é transferido para a raia do Sistema, que executa automaticamente as tarefas de receber a avaliação,registrar os dados no banco de dados e enviar uma notificação de confirmação. Após a notificação, o fluxo retorna para a raia do Cliente, encerrando-se no evento "Avaliação registrada". Na raia do Barbeiro, existe a tarefa de visualizar as avaliações, que funciona como uma etapa de acompanhamento dos feedbacks recebidos.

##### 3.3.4.2  Detalhamento das atividades do usuário (user tasks)
Os tipos de dados utilizados no processo são:

* Área de texto: campo de texto de múltiplas linhas
* Caixa de texto: campo de texto de uma linha
* Lista: campo de lista suspensa
* Link: campo que armazena uma URL
* Número: campo numérico
* Data: campo do tipo data (dd-mm-aaaa)
* Hora: campo do tipo hora (hh:mm:ss)
* Data e Hora: campo do tipo data e hora
* Seleção única: campo com opções mutuamente exclusivas
* Seleção múltipla: campo com uma ou várias opções 
* Tabela: conjunto de dados estruturados


**1 Acessar avaliações**
| **Campo**         | **Tipo**       | **Restrições** | **Valor default** |
| ----------------- | -------------- | -------------- | ----------------- |
| serviço realizado       | Tabela           | -              | -        |
| Sua avaliação    | Tabela      | -              | -        |
| Como você avalia o serviço      | Seleção múltipla        | -              | -        |
| Deixe um comentário      | Caixa de texto      | -              | -        |

| **Comandos** | **Destino**     | **Tipo** |
| ------------ | -------------   | -------- |
| avaliações |avaliar serviço | Link  |
| enviar avaliação  |receber avaliação | Link  |
| editar avaliação  |receber avaliação | Link  |
| excluir avaliação  |receber avaliação | Link  |


**2 Visualizar avaliações**
| **Visualizações**                       | **Tipo** | **Restrições**  | **Valor default** |
| -------------------             | -------- | --------------- | ----------------- |
| últimas avaliações              | Tabela   | somente leitura | automático        |

| **Comandos**               | **Destino**                       | **Tipo** |
| ------------               | ---------------------             | -------- |
| carregar mais avaliações   | Amplia a lista de avaliações      | automático  |
| mais recentes              | exibe as avaliações mais recentes | Seleção única   |
