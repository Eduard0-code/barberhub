### 3.3.5 Processo 5 - (Gestão do Estoque de Material da Barbearia)

O processo de gestão de estoque tem como objetivo controlar a quantidade de materiais utilizados na barbearia, garantindo que não faltem itens essenciais para a realização dos serviços. No cenário atual (AS IS), o controle de estoque é feito manualmente, o que pode gerar esquecimentos e falta de materiais.

No cenário proposto (TO BE), o sistema realiza o controle automático da quantidade de itens e alerta o barbeiro quando o estoque estiver baixo. Esse processo melhora a organização e evita interrupções nos atendimentos por falta de produtos.

O fluxo se inicia na raia do Barbeiro com o evento "Necessidade de uso de material", seguido pelas tarefas de "Utilizar material" e "Atualizar quantidade em estoque". Ao realizar essa atualização, o fluxo é transferido para a raia do Sistema, que executa a tarefa automática de "Receber atualização de estoque". Com os dados processados, o sistema aciona um gateway de decisão para verificar se o "Estoque está baixo?". Caso o estoque esteja em níveis normais (NÃO), o processo segue diretamente para o encerramento no evento "Estoque atualizado". Se o nível for crítico (SIM), o sistema gera um alerta e verifica a necessidade de compra, devolvendo o fluxo para a raia do Barbeiro. O profissional então realiza o "Registro de reposição", que reinicia o ciclo de atualização de quantidade até que o estoque seja normalizado e o processo finalizado.

##### 3.3.5.2 Detalhamento das atividades do usuário (user tasks)

Os tipos de dados utilizados no processo são:

* Área de texto: campo de texto de múltiplas linhas
* Caixa de texto: campo de texto de uma linha
* Lista: campo de lista suspensa
* Número: campo numérico
* Data: campo do tipo data (dd-mm-aaaa)
* Hora: campo do tipo hora (hh:mm:ss)
* Seleção única: campo com opções mutuamente exclusivas
* Tabela: conjunto de dados estruturados

**1 Atualizar quantidade em estoque**
| **Campo**             | **Tipo**       | **Restrições** | **Valor default** |
| --------------------  | -------------- | -------------- | ----------------- |
| material utilizado    | Caixa de texto | obrigatório    | -                 |
| quantidade utilizada  | Número         | obrigatório    | -                 |
| observações           | Área de texto  | opcional       | -                 |

| **Comandos**    | **Destino**                       | **Tipo** |
| -------------   | --------------------------------- | -------- |
| registrar baixa | receber atualização de estoque    | Link     |

**2 Registrar reposição**
| **Campo**                | **Tipo**       | **Restrições** | **Valor default** |
| ------------------------ | -------------- | -------------- | ----------------- |
| material                 | Lista          | obrigatório    | -                 |
| quantidade a adicionar   | Número         | obrigatório    | -                 |
| custo total              | Número         | obrigatório    | -                 |
| fornecedor               | Caixa de texto | obrigatório    | -                 |

| **Comandos**        | **Destino**                       | **Tipo** |
| ------------        | --------------------------------- | -------- |
| confirmar reposição | receber atualização de estoque    | Link     |
