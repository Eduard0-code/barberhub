### 3.3.5 Processo 5 - (Gestao do Estoque de Material da Barbearia)

O processo de gestao de estoque tem como objetivo controlar a quantidade de materiais utilizados na barbearia, garantindo que nao faltem itens essenciais para a realizacao dos servicos. No cenario atual (AS IS), o controle de estoque e feito manualmente, o que pode gerar esquecimentos e falta de materiais.

No cenario proposto (TO BE), o sistema realiza o controle automatico da quantidade de itens e alerta o barbeiro quando o estoque estiver baixo. Esse processo melhora a organizacao e evita interrupcoes nos atendimentos por falta de produtos.

O fluxo se inicia na raia do Barbeiro com o evento "Necessidade de uso de material", seguido pelas tarefas de "Utilizar material" e "Atualizar quantidade em estoque". Ao realizar essa atualizacao, o fluxo e transferido para a raia do Sistema, que executa a tarefa automatica de "Receber atualizacao de estoque". Com os dados processados, o sistema aciona um gateway de decisao para verificar se o "Estoque esta baixo?". Caso o estoque esteja em niveis normais (NAO), o processo segue diretamente para o encerramento no evento "Estoque atualizado". Se o nivel for critico (SIM), o sistema gera um alerta e verifica a necessidade de compra, devolvendo o fluxo para a raia do Barbeiro. O profissional entao realiza o "Registro de reposicao", que reinicia o ciclo de atualizacao de quantidade ate que o estoque seja normalizado e o processo finalizado.

##### 3.3.5.2 Detalhamento das atividades do usuario (user tasks)

Os tipos de dados utilizados no processo sao:

* Area de texto: campo de texto de multiplas linhas
* Caixa de texto: campo de texto de uma linha
* Lista: campo de lista suspensa
* Numero: campo numerico
* Data: campo do tipo data (dd-mm-aaaa)
* Hora: campo do tipo hora (hh:mm:ss)
* Selecao unica: campo com opcoes mutuamente exclusivas
* Tabela: conjunto de dados estruturados

**1 Atualizar quantidade em estoque**
| **Campo**             | **Tipo**       | **Restricoes** | **Valor default** |
| --------------------  | -------------- | -------------- | ----------------- |
| material utilizado    | Caixa de texto | obrigatorio    | -                 |
| quantidade utilizada  | Numero         | obrigatorio    | -                 |
| observacoes           | Area de texto  | opcional       | -                 |

| **Comandos**    | **Destino**                       | **Tipo** |
| -------------   | --------------------------------- | -------- |
| registrar baixa | receber atualizacao de estoque    | Link     |

**2 Registrar reposicao**
| **Campo**                | **Tipo**       | **Restricoes** | **Valor default** |
| ------------------------ | -------------- | -------------- | ----------------- |
| material                 | Lista          | obrigatorio    | -                 |
| quantidade a adicionar   | Numero         | obrigatorio    | -                 |
| custo total              | Numero         | obrigatorio    | -                 |
| fornecedor               | Caixa de texto | obrigatorio    | -                 |

| **Comandos**        | **Destino**                       | **Tipo** |
| ------------        | --------------------------------- | -------- |
| confirmar reposicao | receber atualizacao de estoque    | Link     |
